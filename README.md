Agri Smart Guide
Agri Smart Guide is a Flutter mobile application designed to help home gardeners, small farmers, and family farms (OPGs) organize their crops and everyday agricultural activities.

Developed by Geta Software, a five-member student team, as part of the Analiza i razvoj programa course at the Faculty of Organization and Informatics (FOI).
Planned features
- User accounts and a personalized dashboard
- Garden plots, crop catalog, and planting records
- Tasks, activity calendar, notes, and reminders
- Weather forecasts and rule-based weather recommendations
- Soil measurements and basic advisory insights
- Illustrative vegetation/NDVI insights using demo data
  Technology
- Flutter / Dart — Android application
- Firebase Authentication — user accounts (planned)
- Cloud Firestore — application data (planned)
- Open-Meteo API — weather data (planned)
  Android is the primary target platform. iOS support may be considered in the future.
  Getting started
1. Install the Flutter SDK and Android Studio.
2. Clone the repository and open the project folder.
3. Run flutter pub get.
4. Start an Android emulator or connect an Android device.
5. Run flutter run.
   Project status: Initial setup. The listed features are planned and are not yet implemented.
